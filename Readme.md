## Python Control Flow Module

The current notebook-based assignment set focuses on Python control flow, including:

- simple and nested conditions
- `if`, `if-else`, and `if-elif-else` statements
- `for` and `while` loops
- `break`, `continue`, and `pass`
- factorial and digit-sum logic
- prime number checks
- Fibonacci sequence generation

These exercises are foundational for writing logic-heavy data science and machine learning programs.

## Getting Started

### 1. Clone the repository

```bash
git clone <repository-url>
cd ML
```

### 2. Create a virtual environment

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Open the notebooks

Use Jupyter Notebook or VS Code notebooks to work through the assignments.

## Recommended Workflow

1. Read the assignment instructions carefully.
2. Try to solve each problem independently.
3. Use the solutions notebook only for reference or verification.
4. Practice rewriting and improving the code.
5. Keep notes and experiment with variations.
